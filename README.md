# xlsx2md — Excel(構成図チェック観点など)をMarkdownの表に変換する

Excel(.xlsx / .xlsm)の各シートを、Agentのツールが読める **md表(1ファイル1表)** に変換します。
元ファイル名をそのまま使い、拡張子だけ `.md` に変えます。参照している別シート(サブページ)も個別のmdにし、リンクでつなぎます。

## 必要なもの

- Python 3.9 以上(Anaconda に含まれるもので可)
- openpyxl(Anaconda には同梱。無い場合: `pip install openpyxl`)

## フォルダ構成

```
xlsx2md/
├── xlsx2md.py      … 変換スクリプト
├── README.md       … このファイル
├── input/          … 元ファイル(.xlsx / .xlsm)を置く
│   └── 構成図チェック観点一覧.xlsx
├── output/         … 変換後ファイル(.md)が出力される
│   ├── 構成図チェック観点一覧.md                                   ← 先頭シート(元ファイル名と同じ)
│   └── 構成図チェック観点一覧_Vnet・VPC外に記載する代表サービス一覧.md ← 2枚目以降のシート
└── sample/         … 動作確認用のサンプルExcel
```

## 使い方

Anaconda Prompt(またはターミナル)で `xlsx2md` フォルダに移動して実行します。

```bash
cd xlsx2md

# 1) input フォルダの全Excelを output へ変換(いちばん簡単)
python xlsx2md.py

# 2) ファイルを指定して変換
python xlsx2md.py input/構成図チェック観点一覧.xlsx

# 3) 入力フォルダと出力先を指定
python xlsx2md.py "C:\work\観点表" -o "C:\work\md"

# 4) 元ファイル名.md にするシートを指定(既定は先頭の表示中シート)
python xlsx2md.py --main-sheet "構成図チェック観点"

# 5) 出力しない列を指定(見出し名をカンマ区切り)
python xlsx2md.py --drop-columns "判定トリガー（削除予定）"
```

実行すると、シートごとに「表の行数 / 列数 / 表の範囲の由来」を表示します。行数がExcelの目視と合っていることを確認してください。

```
変換: 構成図チェック観点一覧.xlsx
  - 構成図チェック観点一覧.md: 表の行数 51 / 列数 14 / テーブル 'テーブル1' (A6:N57)
  - 構成図チェック観点一覧_Vnet・VPC外に記載する代表サービス一覧.md: 表の行数 12 / 列数 3 / 見出し行を自動判定 (行 1)
完了: 2 ファイルを output に出力しました
```

## 変換ルール

| 項目 | ルール |
|---|---|
| ファイル名 | 先頭シート(または `--main-sheet`)→ `<元ファイル名>.md`。他のシート → `<元ファイル名>_<シート名>.md`(ファイル名に使えない記号は `_`) |
| 表の範囲 | シートに **Excelのテーブル**(挿入 → テーブル)があればその範囲。無ければ先頭30行のうち「値のあるセルが最も多い行」を見出し行として自動判定 |
| 表以外の行 | mdの先頭に `# シート名`、`元ファイル: … / シート: … / 変換日時: …`、`関連シート: [名前](ファイル)` を書く。**`\|` で始まる行は表の行だけ**(ツールが行数を数える約束) |
| セル内改行 | `<br>` に置き換え |
| 半角の縦棒 `\|` | 全角 `｜` に置き換え(表の区切りと衝突するため) |
| 数値・日付 | `3.0` → `3`、日付 → `yyyy/mm/dd` |
| 結合セル | 左上の値を結合範囲の全セルに広げる |
| 非表示の行・列 | 出力しない(フィルターで隠れた行も同じ)。出力したい場合は `--include-hidden` |
| 非表示のシート | 変換しない。`--include-hidden-sheets` で変換 |
| 空行 | 全列が空の行は出力しない |
| 別シートへの参照 | セルの文中に他のシート名がある場合、そのシートのmdへのリンク `[シート名](ファイル.md)` に置き換える(`--no-link-refs` で無効) |
| 文字の色・太字 | 保持しない(文字だけ)。赤字の修正案なども通常の文字になる |
| 数式 | Excelが保存した計算結果の値を出力する(数式そのものは出さない) |

## 運用のポイント(構成図チェック観点の場合)

1. Excelを直したら、`input` に上書きコピーして `python xlsx2md.py` を実行し、`output` のmdをSharePointのAI連携用フォルダへ配置する(Excelは編集用、mdが配置用の正)。
2. 表の範囲はExcelのテーブルにしておくと確実(テーブル外のメモ行が混ざらない)。
3. 廃止した観点はテーブルから外す(非表示にするだけでも出力されない)。
4. 列の順番は変えない。列を足すときは末尾に追加する(ツール②が列の位置で絞り込むため)。
5. `--drop-columns` で「判定トリガー（削除予定）」のような作業用の列を出力から外せる。
6. 出力の行数がツールの「全行数 / 適用行数」と一致することを、初回だけ確認する。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| `開けません(Excelで開いたままの可能性)` | Excelを閉じるか、ファイルをコピーしてから変換する。`~$` で始まる一時ファイルは自動で無視 |
| 表の行が多い・少ない | テーブルの範囲を確認(テーブル デザイン → テーブルのサイズ変更)。テーブルが無い場合はメモ行が見出し行と誤判定されることがあるので、テーブル化する |
| 見出しが `A`,`B` のように出る | 見出し行のセルが空。テーブルの1行目に見出しを入れる |
| 数式のセルが空になる | Excelで一度保存し直す(計算結果が保存される) |
| 別シート名がリンクにならない | セルの文字列とシート名が完全一致している必要がある(空白や記号の違いに注意) |
| 文字化け | 出力はUTF-8。VS Code等で開く。Excelで開く用途ではない |

## 動作確認

`sample/構成図チェック観点一覧.xlsx`(2シート・非表示行・セル内改行・縦棒・別シート参照を含む)で試せます。

```bash
python xlsx2md.py sample -o output_sample
```
