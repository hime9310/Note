T3〜T5 ツール設定(親Agent > ツール > 各ツールの画面に入れる値)
前提: フロー自体は作成済み。ここは「エージェントに付けたツール」側の設定。3つとも 利用できる対象 = アーキテクチャレビュー票作成_Sheet だけ。
3つとも「実行後」は『生成AIで応答を記述する』にする(応答しない のままだと、子が「受領…未完了」のような1行で止まる。今回の『レビュー票を作成して』の失敗はこれ)。
「説明」は必須。空のままだと詳細に「!」が付き、保存・公開しても使われない。

==================================================
T3 レビュー票データ取得
==================================================
名前: T3 レビュー票データ取得
説明:
アーキテクチャレビュー票作成Agentが処理名「票作成」のとき、最初に1回だけ使う。RITM番号とCSPを受け取り、Teamsスレッド本文(threadText)、CSP(csp)、CSP別アーキテクチャレビュー票テンプレートの全行(template。先頭に「全行数: NN」)、サービス提供対象リソース一覧(resourceList)を返す。データを返すだけで、票の判断や文章の作成はしない。Excel生成・回答回収では使わない。

入力(どちらも「AIで動的に入力する」。カスタマイズで説明を入れる):
- RITM番号: 依頼文のRITM番号。RITM1234567 の形
- CSP: AWS / Azure / GCP のいずれか。【ホスティング判定結果】のCSP
出力(フロー側の名前。すべて文字列): threadText / csp / template / resourceList
実行後: 生成AIで応答を記述する

==================================================
T4 アーキテクチャレビュー票Excel作成
==================================================
名前: T4 アーキテクチャレビュー票Excel作成
説明:
アーキテクチャレビュー票作成Agentが処理名「Excel生成」のときだけ1回使う。RITM番号・CSP・票の行のJSON配列を受け取り、CSP別テンプレートからExcelを作成して行を書き込み、書き込み件数(writtenCount)・保存先リンク(fileUrl)・ファイル名(fileName)を返す。JSONのキーは No. / ステータス / 環境 / 対応区分 / カテゴリ / 指摘概要 / 指摘内容 / 対応ガイドライン・参考資料 の8つ。票作成・回答回収では使わない。

入力(3つとも「AIで動的に入力する」):
- RITM番号: 依頼文のRITM番号。RITM1234567 の形
- CSP: AWS / Azure / GCP のいずれか。依頼文のCSP
- 票データ(JSON): 会話内の最新の【編集指示】の「アーキテクチャレビュー票」①②③の全行を、JSON配列の文字列にしたもの。キーは8つ。"No." は編集指示の番号のまま、"ステータス" は "New"
出力: writtenCount(数値または文字列)/ fileUrl / fileName
実行後: 生成AIで応答を記述する

==================================================
T5 回答済みアーキテクチャレビュー票取得
==================================================
名前: T5 回答済みアーキテクチャレビュー票取得
説明:
アーキテクチャレビュー票作成Agentが処理名「回答回収」のときだけ1回使う。RITM番号を受け取り、Teamsスレッドに添付された回答済みアーキテクチャレビュー票(Excel)を探し、添付の有無(attached: 添付あり / 未添付)、ファイル名(fileName)、全行のテキスト(rowsText。先頭に「全行数: NN」、1行に No. / 指摘概要 / 指摘内容 / 回答)を返す。添付が無ければ attached=未添付 で返す。回答の良し悪しは判断しない。票作成・Excel生成では使わない。

入力(「AIで動的に入力する」):
- RITM番号: 依頼文のRITM番号。RITM1234567 の形
出力: attached / fileName / rowsText
実行後: 生成AIで応答を記述する

==================================================
再作成の順番
==================================================
1. 親Agent > ツール で T4・T5 を削除 → 「ツールの追加」→ フロー から同じフローを選んで追加
2. 名前・説明・入力の説明・実行後 を上の通りに入れて保存
3. T3 も開いて 説明が入っているか / 実行後が『生成AIで応答を記述する』か を確認
4. 親を公開 → 新しいテストセッションで 判定して → 構成図チェックして → レビュー票を作成して
フローの出力名が上と違う場合は、その名前を教えてください(票作成Agentの指示文を合わせます)。
